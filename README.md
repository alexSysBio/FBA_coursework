# FBA coursework

In this repository I have included all resources necessary to generate a metabolic model using cobraPy: https://opencobra.github.io/cobrapy/.
Please study this [paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC3751080/) before jumping onto the code. We will use this paper and additional resources to cover the theory behind genome-scale metaboling modeling.

The goals of the course:
1. To develop an FBA model of central carbon metabolism.
2. Use the model to draw biologically meaningful conclusions.
